# an-lise-cdv
Gerar o gráfico de falsa ocupações do sistema
Arraste e solte o arquivo de eventos CSV
Escolha a data que deseja avaliar falsa ocupação
Escolha o intervalo de horário (* O horário padrão é 6h as 22h para fins de comparação)
Serão gerados gráficos por domínio e um arquivo CSV com o resultado das oscilações
